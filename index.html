Good to know

A few questions.

Need something else? Ask in the Solcord server.

Is Solcord a separate Discord app?

Solcord is a desktop mod for your installed Discord client. This download contains the Windows installer. It adds Solcord features to Discord; you keep using your existing Discord account.

Who can see my custom profile and badges?

Other updated Solcord users with the relevant plugins and access to the Solcord profiles channel. No separate account link is needed. Profile posts in that channel can be read by members with channel access, so only share information you want them to see. Standard Discord users won’t see these additions.

Can anyone use an Owner or Developer badge?

Staff badges require a valid key for the matching badge. Shared staff badges use signed verification tied to the posting Discord user. The buttons on this page only demonstrate how the badges look; they don’t unlock a real badge.

How do updates work?

Updates are manual for now. Download the latest installer, fully quit Discord, then run it to update your installation. Discord changes can affect mods, so check the Solcord server for compatibility updates.

What does the online counter track?

It counts participating Solcord installations that checked in during the last 3 minutes. It’s an approximate active installation count, rather than unique people or total downloads. Session registration is enabled by default and can be turned off in Solcord settings. Visiting this website doesn’t register a session.

How do I remove Solcord?

Fully quit Discord, open the Solcord installer, and use its uninstall option. Then reopen Discord.
